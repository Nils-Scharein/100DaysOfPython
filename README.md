# 100 Days of Code – Python Bootcamp

This is my personal project repository for the [100 Days of Code: The Complete Python Pro Bootcamp for 2024](https://www.udemy.com/course/100-days-of-code/) by Dr. Angela Yu on Udemy.

## 📁 Contents

This repository contains my solutions, notes, and experiments from each of the 100 days of the course. It covers both foundational concepts and practical projects using Python.

> 🔁 **Currently paused at Day 35** – May be continued in the future.

### 📦 Folder Structure

- Each day has its own folder, named `DayXX`, containing the corresponding exercises and/or projects.
- Files are usually named according to the lecture or project topic (e.g., `main.py`, `game.py`, etc.).
- Some days may include assets such as images, text files, or JSON data for projects.
